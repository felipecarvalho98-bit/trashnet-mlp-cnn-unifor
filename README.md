# TrashNet — pacote final

Projeto da atividade de Redes Neurais Artificiais (UNIFOR): MLP, CNN, extensão YOLO e experimento complementar AMD DirectML.

| Pasta | Conteúdo |
|---|---|
| `ARTIGO/` | Artigo em PDF e DOCX editável. |
| `trashnet_mlp_cnn_unifor/` | Código principal, dataset, notebook e resultados E1–E6/YOLO. |
| `GPU_DirectML_E3/` | Implementação PyTorch/DirectML e execução da RX 5500 XT. |
| `ARQUIVOS_BACKUP/` | Cópias dos resultados originais. |

O notebook funciona localmente e no Colab. Permite consultar o backup ou iniciar E1–E6 em uma pasta nova. Os experimentos oficiais foram executados em CPU; YOLO e DirectML são extensões separadas.
