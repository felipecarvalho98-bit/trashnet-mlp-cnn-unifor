# Notebook local e Google Colab

`notebooks/00_Execucao_Colab.ipynb` oferece duas opções: consultar os resultados já salvos ou executar novamente E1–E6. A nova execução utiliza uma pasta separada para preservar o backup.

O notebook identifica Google Colab ou Jupyter/VS Code local e utiliza os mesmos módulos de `src/`. Não exige montagem do Google Drive. O armazenamento do Colab é temporário; por isso, a execução cria um arquivo ZIP de resultados.

Os resultados oficiais incluídos no projeto foram produzidos localmente em CPU. Uma nova execução em outro ambiente deve ser identificada separadamente, com seu hardware e seus próprios resultados.
